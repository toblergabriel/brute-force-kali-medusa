# brute-force-kali-medusa
Simulação de ataques de força bruta (FTP, Web/DVWA e SMB) usando Kali Linux e Medusa em ambiente controlado (Metasploitable 2 + DVWA), com enumeração via enum4linux, documentação de erros de sintaxe cometidos no processo e recomendações de mitigação. Projeto do desafio “Explorando Vulnerabilidades com Kali Linux e Medusa” (DIO).
